# Sources: 2026 Gartner Magic Quadrant for Enterprise AI Coding Agents

**Report:** Gartner, *Magic Quadrant for Enterprise AI Coding Agents*, published 20 May 2026. It's the first MQ under this name and replaces the *Magic Quadrant for AI Code Assistants* (2024, 2025).
**Gartner analysts to know:**
- Philip Walsh (author)
- Keith Holloway (author)
- Matt Brasier (author)
- Nitish Tyagi (author)
- Neha Agarwal (author)
- Manjunath Bhat, Distinguished VP Analyst. Presents the MQ: "Magic Quadrant for Enterprise AI Coding Agents" session at Gartner IT Symposium/Xpo, Brisbane, 15 Sep 2026 ([session page][gsym])

12 vendors evaluated. All URLs below were loaded and checked on 2026-10-15.

## Tiers (set by Ari)
- **Tier 1:** Cursor, OpenAI, Anthropic, GitHub (2026 Leaders)
- **Tier 2:** GitLab, AWS, Google Cloud (prior Leaders). GitLab isn't in the 2026 MQ but stays in tier 2: its AR person ran the 2024 and 2025 cycles with the same analysts.
- **Tier 3:** Alibaba Cloud (China-based AR team, so likely fewer US analyst relationships), Tabnine, Atlassian, BytePlus, JetBrains
- **Out of scope for now:** Cognition

## 2025 MQ for AI Code Assistants (for tier 2b)

Gartner, *Magic Quadrant for AI Code Assistants*, published 15 September 2025 (https://www.gartner.com/en/documents/6948266). 14 vendors. Positions are read off the Gartner graphic in GitLab's announcement (https://about.gitlab.com/blog/gitlab-named-a-leader-in-the-2025-gartner-magic-quadrant-for-ai-code-assistants/, image https://res.cloudinary.com/about-gitlab-com/image/upload/v1758121248/jfkmhddve6qvlg79xico.png). Visual Studio Magazine confirms the Leaders: https://visualstudiomagazine.com/articles/2025/09/17/report-github-tops-ai-coding-assistants-with-microsoft-related-cautions.aspx

- **Leaders:** GitHub, Amazon, Cognition (Windsurf), GitLab, Google Cloud
- **Challengers:** Anysphere (Cursor), Alibaba Cloud
- **Visionaries:** Harness, Qodo, Tabnine, Augment Code
- **Niche Players:** Tencent Cloud, IBM, JetBrains

**In 2025 but not in the 2026 agents MQ:** GitLab (already tier 2), Harness, Qodo, Augment Code, Tencent Cloud, IBM. The last five are **tier 2b** (Ari, for now).
